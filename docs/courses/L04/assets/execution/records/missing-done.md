# 工作台 V0 能力合同（参考复验输入）

## 来源
承接 L01 工作台建设目的、L02 AGENTS 和 L03 六段解析要求；本次为参考实现复验，不是学生建设或人工接受记录。
## 目标
复验 Spec、任务、受控执行、范围检查、最小 Eval 和待人工审核的连接。
## 非目标
不执行库存导出开发，不作人工接受，不声称已完成学生建设。
## 约束
只使用独立运行目录保存记录；失败保留证据；检查通过仍须等待人审。
## 验收用例
1. 有效合同解析出六个字段，缺完成定义时明确拒绝。
2. 执行替身越界即使退出码为 0 也被阻止。
3. 参考任务通过 Eval 后停在 review，reviewed_by 为空。
4. 未独立接受的 A 不能启动 B。
