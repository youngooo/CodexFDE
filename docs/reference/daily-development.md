# 日常研发入口

日常研发统一从工作台首页的“事项与决策”开始。先选择项目，再描述问题、讨论范围、确认方案和执行授权。项目准备见[项目驱动交付](项目驱动交付.md)。

日常维护可能从全绿基线开始。新需求仍须增加对应验收；已有检查通过不证明新需求已经实现。L04 以后的课堂隔离实验另有起始红灯、范围内 Diff 和执行后绿灯要求，按当讲合同执行。

完成一次执行后，读取对应候选的报告和修改，复验正常与失败路径，再具名审核。返工、服务重启或后续集成都应沿用原事项的证据链，不重建一条无关联的成功记录。

可复用经验先保存为带来源和适用范围的候选，经过审核后供后续事项召回。召回、人工采用、执行效果是三个不同事实；详见[工作台范式与闭环建设](../architecture/工作台范式与闭环建设.md)。
