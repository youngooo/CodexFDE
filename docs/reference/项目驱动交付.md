# 从项目进入交付

打开工作台首页 `http://127.0.0.1:8001/`，在“事项与决策”登记已有本地仓库，或用 Git 链接克隆到新目录。新目录不能覆盖已有文件；项目登记本身不会安装依赖或完成验收。

创建事项前核对所属项目。工作台源码和独立 FlowERP 使用不同项目身份；经验检索、源码范围、检查配置及候选都必须属于该项目。已有事项不能通过更换显示名称迁移到另一个项目。

先记录现场问题、目标和约束，再组织调研与澄清。确认执行前，登记该项目实际可用的解释器和 Eval 命令，核对写集、输入版本和授权。执行后对照实际 Diff、检查结果及业务状态，由具名审核者决定接受或返工。

候选通过不自动写回主项目。集成前再次核对源文件是否变化；变化时停止并重新确认，保留原候选和失败记录。详细操作见[仓库总入口](../../README.md)和[网页代码执行](工作台网页代码执行.md)。
